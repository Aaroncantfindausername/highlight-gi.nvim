==============================================================================
1. Setup                                                 *my_plugin-setup*

Call `setup()` in your Neovim config:
>lua
    require("my_plugin").setup({
      greeting = "Hello from my plugin!",
      verbose = false,
    })
<

Options:

*greeting*
    Message used by `:MyPluginHello`.

*verbose*
    If `true`, prints extra debug information.

==============================================================================
2. Commands                                           *my_plugin-commands*

:MyPluginHello [message]                                  *:MyPluginHello*
    Print a greeting.

    If [message] is given, that message is printed instead of the
    configured greeting.
